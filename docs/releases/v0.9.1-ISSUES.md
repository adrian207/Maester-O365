## Critical Bugs (P0)

### Issue #1: Docker Compose fails on Windows with volume mount permissions

**Labels:** `bug`, `priority: critical`, `docker`, `windows`

**Description:**
Docker Compose deployment fails on Windows systems due to volume mount permission issues.

**Steps to Reproduce:**
1. Install Docker Desktop on Windows
2. Clone repository
3. Run `docker-compose up -d`
4. Observe permission denied errors

**Expected Behavior:**
Docker Compose should start successfully on Windows

**Actual Behavior:**
```
Error: Permission denied: './data/postgres'
```

**Environment:**
- OS: Windows 10/11
- Docker Desktop: Latest
- Version: v0.9.0

**Proposed Solution:**
- Update docker-compose.yml with Windows-compatible volume syntax
- Add Windows-specific documentation
- Test on Windows 10 and 11

**Acceptance Criteria:**
- [ ] Docker Compose works on Windows 10
- [ ] Docker Compose works on Windows 11
- [ ] Documentation updated with Windows notes
- [ ] Test case added

## Instructions for Creating Issues

### Creating Issues on GitHub

```bash
# Use GitHub CLI to create issues efficiently
cd c:\Github\Maester-O365

# Create milestone first
gh issue milestone create v0.9.1 --due-date 2025-11-30

# Create individual issues
gh issue create --title "Docker Compose fails on Windows" \
  --body "$(cat issue-template.md)" \
  --label "bug,priority: critical,docker,windows" \
  --milestone "v0.9.1"
```

### Bulk Import

To bulk import these issues:

1. Copy each issue section above
2. Go to https://github.com/adrian207/Maester-O365/issues/new
3. Paste title and description
4. Add appropriate labels
5. Assign to v0.9.1 milestone
6. Submit

Or use the GitHub CLI commands provided in each issue.
